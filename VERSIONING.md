# Versioning — Production Special-Order release candidate

| Field | Value |
|---|---|
| Package (`pyproject.toml`) | `0.4.0rc1` (PEP 440) |
| Git tag | `v0.4.0-rc1` |
| Certification docs | `PHASE_H_RELEASE.md`, `RELEASE_NOTES.md`, `KNOWN_LIMITATIONS.md` |
| Semantic freeze | `PRODUCTION_SEMANTICS.md` SF-1..SF-8 |

This identifier certifies the **Production Special-Order** path after
Phases C–G. It is not a claim that Trading, Doctrine, Refining, Station
Trading, Android, or Windows packaging are newly 1.0.

Prior annotated tags on this repo: `v0.1.0` … `v0.3.2`. Those tags did not
bump `pyproject.toml` (it remained `0.2.0`). `0.4.0rc1` is the first
package version that matches this Special-Order RC.

The tag is immutable. Changes after it need a new version.
